      Read the projection

      1. The Azure ontology records which readings measure the cluster. It does not assign a health state.
      2. GQL picks the newest reading that was both sampled and received by the chosen time.
      3. The query compares the reading with the example CPU thresholds. An old reading becomes unknown, not healthy.

      Show the GQL that ran in your browser

      Your browser runs the lab’s GQL query in Grafeo WebAssembly and draws the result. It does not connect to Azure or send queries to a server. These thresholds are examples, not recommendations.
